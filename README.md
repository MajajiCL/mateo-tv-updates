# Mateo TV — Canal de Actualizaciones Automáticas (OTA)

Repositorio público de distribución para **Mateo TV** (el código fuente se mantiene privado en `MajajiCL/mateo-tv`).

- **Catálogos silenciosos:** editar `catalog/verified_*.json` y subir `catalogVersion` en `update.json` actualiza canales, películas y series automáticamente sin clics en todos los televisores.
- **Actualización de APK:** publicar un nuevo Release con el archivo `MateoTV.apk` y subir `versionCode`/`versionName` en `update.json`.
- **Enlace permanente del último APK:** https://github.com/MajajiCL/mateo-tv-updates/releases/latest/download/MateoTV.apk
